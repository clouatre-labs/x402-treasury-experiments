# Record Extraction: usdc-fiat-sweep-api

Instructions for transcribing raw session artifacts in `sessions/raw/` into run records in `sessions/`. For this experiment the [sweep.ts](sweep.ts) script performs the transcription automatically at write time and validates each record against the schema; these rules document what it does and govern any manual correction.

1. Transcribe exactly. No rounding beyond what the source shows. Raw API responses are stored verbatim in `sessions/raw/` before any field is derived.
2. Do not infer missing values. Amounts and identifiers are never null; a value missing from the raw artifact is a transcription error and must be resolved against the raw artifacts. Per the schema, `amount_usdc` is nullable (non-null for every executed tranche; null only for the pre-registered `not_executed` replicate, which requires a populated `notes` entry), and `network_fee_usd` is nullable (null requires a populated `notes` entry). The three timestamp fields (`timestamp_sent`, `timestamp_coinbase_credit`, `timestamp_fiat_spendable`) may be null only when the hop failed or was unobserved; every null timestamp requires a populated `notes` entry explaining which hop failed or was unobserved.
3. One record per tranche, using the schema in [DATA_DICTIONARY.md](../../DATA_DICTIONARY.md) (`usdc-fiat-sweep-api run-record schema`): `tranche_id`, `replicate`, `executed`, `synthetic`, `amount_usdc`, `tx_hash_in`, `deposit_address`, `convert_quote_id`, `usdc_mid`, `mid_observed_at`, `timestamp_sent`, `timestamp_coinbase_credit`, `timestamp_fiat_spendable`, `fiat_received`, `network_fee_usd`, `fixed_fee_usd`, `quoted_fee_usd`, `realized_fee_pct`, `spread_vs_mid_pct`, `funding_tx_hash`, `notes`. Record the on-chain transaction hash of the single pre-funding transfer in `funding_tx_hash`; it is identical on every record of the experiment since there is exactly one transfer.
4. `usdc_mid` is the USDC-USD spot price captured immediately before the convert quote request, with its capture time in `mid_observed_at`; `spread_vs_mid_pct` is derived from `fiat_received`, `amount_usdc`, and `usdc_mid`, not recorded directly. `realized_fee_pct` is derived from `fixed_fee_usd`, `network_fee_usd`, and `amount_usdc`.
5. The convert fee is captured verbatim from the quoted fee field of the Advanced Trade convert quote response; it is the value of `quoted_fee_usd` and `fixed_fee_usd`. No schedule knowledge is substituted for the API value.
6. Timestamps are transcribed in the format the source shows (chain receipts in Unix seconds converted to ISO 8601 with a UTC offset; API timestamps verbatim); note the timezone if the source does not show UTC.
7. If any tranche aborted mid-run, the record carries a populated `notes` entry stating which hop failed; the tranche is never re-run.
8. Raw artifacts stay untouched in `sessions/raw/`; records are derived copies only.
